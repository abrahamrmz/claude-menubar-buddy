# Créditos de los sonidos

Todos los sonidos de esta carpeta tienen licencia CC0 1.0 (dominio público). Abajo, cada archivo dice de dónde salió, bajo qué licencia, con qué SHA-256 se bajó y qué se le cambió. Las URLs de GitHub están fijadas a un commit, así que siguen apuntando al mismo archivo aunque el repositorio de origen cambie.

`SoundFilesAuditTests` lee este archivo: cada sección empieza con `## <archivo>` y sigue con líneas `- clave: valor`. Cualquier sonido que se agregue necesita su sección con las mismas claves.
